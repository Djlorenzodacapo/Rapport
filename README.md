# Monteur Rapport Pro

Professionelle GitHub-Pages-fähige Rapport-App.

## Enthalten

- lokale IndexedDB-Datenbank
- Monteurverwaltung
- Netzbetreiberverwaltung
- Rapportverwaltung
- Lizenzschutz
- Lizenzgenerator für Eigentümer/Admin
- Backup/Restore als JSON
- PDF/Druckfunktion
- responsive Mobile-PWA-Oberfläche

## Start

`index.html` im Browser öffnen oder den Ordner auf GitHub Pages veröffentlichen.

## Hinweis Lizenz

Der lokale Lizenzschutz ist für eine reine Frontend-App praktikabel, aber nicht unknackbar. Für kommerzielle Lizenzierung mit Sperrung/Gerätebindung wird in Version B ein Backend empfohlen.
